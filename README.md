# SDC310LProject

PHP/MySQL online store course project for SDC310.

## Technologies

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## Features

- Product catalog
- Product details
- Shopping cart
- User registration
- User login
- User logout
- Checkout
- Order creation
- Product management
- User management
- MySQL database connectivity
- CRUD database operations

## XAMPP Setup

1. Start Apache in XAMPP.
2. Start MySQL in XAMPP.
3. Place the project folder inside:

   C:\xampp\htdocs\

4. Open phpMyAdmin.
5. Create/import the database using:

   database/database.sql

6. Open the application in a browser:

   http://localhost/SDC310LProject/

## Database

The application uses a MySQL database named:

sdc310_store

The database contains:

- users
- products
- orders
- order_items
